1 What is Boolean Logic?
🔘 Boolean Logic & Variables

Boolean Logic is a system of logic in which variables can have only two possible values: 0 (False/OFF) and 1 (True/ON). Widely used in digital electronics & computer systems.

Boolean Variable A variable that can hold only two values: 0 or 1.
Examples: A, B, C, X, Y, Z
Boolean Expression Formed using Boolean variables and logical operators.
Examples: A + B, A · B, A'
0 = False / OFF 1 = True / ON

4 NOT Operator & NOT Gate
🔄 NOT — Complement / Inverter

NOT is a unary operator — it operates on one input and reverses its value. Also called Complementation.

A A'
01
10
NOT 0 = 1
NOT 1 = 0
Changes 0 → 1 and 1 → 0
🔌 NOT Gate (Inverter)

The NOT gate has one input and one output. The output is always the opposite (complement) of the input.

Input ──▷○── Output

0 ──▷○── 1
1 ──▷○── 0
💡 The NOT gate is also called an Inverter because it inverts the signal.

7 Logic Gates — The Big Picture
🔌 What is a Logic Gate?

A logic gate is an electronic circuit that operates on one or more input signals and produces an output signal. Each gate implements a Boolean operator.

8 De Morgan's Theorems
📜 First Theorem
Complement of OR = AND of Complements
(A + B)' = A' · B'

When the bar enters → OR changes to AND and each variable gets complemented.

X Y X+Y (X+Y)' X' Y' X'·Y'

✅ (X+Y)' and X'·Y' are identical!

📜 Second Theorem
Complement of AND = OR of Complements
(A · B)' = A' + B'

When the bar enters → AND changes to OR and each variable gets complemented.

X Y X·Y (X·Y)' X' Y' X'+Y'
0001111

1110000

✅ (X·Y)' and X'+Y' are identical!

⭐ De Morgan's — Must Memorise
First Theorem (A + B)' = A'B'
(A + B + C)' = A'B'C'
OR → AND
Second Theorem (AB)' = A' + B'
(ABC)' = A' + B' + C'
AND → OR
💡 Shortcut: Bar enters bracket → operator changes (+ ↔ ·) and each variable gets its own bar.

Term 1: AB A AND B

Term 2: AC' A AND NOT C
→ NOT gate (C), then AND gate (A, C')
Term 3: B'A'C NOT B AND NOT A AND C
→ NOT gates (B, A), then AND gate (B', A', C)

Finally: OR gate combines AB, AC', and B'A'C to produce F.

11 Pre-Exam Quick Revision
✅ Understand Before Questions
  • Boolean values: 0 = False, 1 = True
  • Truth table rows = 2ⁿ
  • NOT: 0→1, 1→0 (unary, complement)
  • OR: ANY 1 → 1 (symbol: +)
  • AND: ALL 1 → 1 (symbol: ·)
  • NOT/OR/AND truth tables (2 & 3 inputs)
  • Logic gate = electronic circuit
  • NOT gate = Inverter
  • De Morgan 1: (A+B)' = A'B'
  • De Morgan 2: (AB)' = A'+B'
  • Read Boolean expressions correctly
  • Circuit design: NOT → AND → OR
