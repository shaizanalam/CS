1 Python Character Set
🔤 What is a Character Set?

A character set is a set of valid characters that a language can recognize. Python has the following character set:

  • Letters: A(65) - Z(90) , a(97) - z(122)
  • Digits: 0(48) - 9(57)
  • Special Symbols: space, +, -, etc.
  • Whitespace: Blank Space, tabs, newline
2 Tokens / Lexical Units
🧩 What is a Token?

The smallest individual unit in a program is known as a Token or a lexical unit.

Python has 5 main types of tokens:

1. Keywords
2. Identifiers (Names)
3. Literals
4. Operators
5. Punctuators
🔑 2.1 Keywords

A keyword is a word having special meaning reserved by the programming language.

Note: Most of the keywords will be available in small case only.

Examples:
True, False, for, in, not, if, else, elif, etc.
🏷️ 2.2 Identifiers (Names)

Identifiers are fundamental building blocks of a program and are used as the general terminology for the names given to different parts of the program such as - variables, objects, classes, functions, lists, dictionaries, strings, tuples, etc.

📜 Identifier Forming Rules
  1. The first character must be a letter or an underscore (_).
  2. An identifier must not contain any space.
  3. Uppercase and lowercase identifiers are considered differently by Python (Python is case-sensitive).
  4. Digits are only allowed in between or at the last of the identifier.
  5. No special characters are allowed in an identifier except UNDERSCORE.
  6. An identifier must not be a keyword of Python.
Valid Identifiers:
Myfile, In, File420, _CS, _12, DOB_08_07_21
Invalid Identifiers:
Data-Rec (-), 29Kohli (Starts with digit), in (keyword), My.life (.), &name (&), Import (If considered keyword)
🔢 2.3 Literals / Data / Values / Constants

Literals are data items that have a fixed value. Python allows several kinds of literals:

Type Details & Sub-types
Numeric Literals a. Integer (int): All +ve and -ve whole numbers without decimal point.
- Decimal: 0 to 9 (e.g., 155, 859)
- Octal: Starts with 0o or 0O, range 0 to 7 (e.g., 0o28 is invalid, 0o762 is valid)
- Hexadecimal: Starts with 0x or 0X, range 0-9 and A-F (e.g., 0XBA9)

b. Float: Numbers with a decimal point (e.g., 3.14). Supports Fractional Form (2.0, -13.0) and Exponent Form (Mantissa E Exponent, e.g., 123E04).

c. Complex: Form of a+bi (e.g., 12 + 2j).
String Literals A sequence of characters surrounded by quotes (single/double/triple).
- Single-line strings: Terminate in one line ('text' or "text").
- Multiline strings: Spread across multiple lines. Created using a backslash (\) at the end of normal quotes, or by using triple quotes ('''text''').
Boolean Literals Used to represent one of the two Boolean values: True or False.
Special Literal None: Used to indicate the absence of a value.
⚠️ Nongraphic Characters (Escape Sequences): Characters that cannot be typed directly (like backspace, tab). Represented by a backslash (\) followed by a character.
Examples: \n (Newline), \t (Tab), \\ (Backslash), \' (Single Quote), \" (Double Quote).
🧮 2.4 Operators

Operators are tokens that trigger some computation/action when applied to variables and other objects (called Operands) in an expression.

1. Unary Operator
Requires one operand to operate upon.
Examples: Unary plus (+), Unary minus (-), Logical negation (not)
2. Binary Operator
Requires two operands to operate upon.
Categories: Arithmetic, Relational, Logical, Assignment, Membership, Identity
Operator Type Symbols / Keywords
Arithmetic + (addition), - (subtraction), * (multiplication), / (division), % (modulus/remainder), ** (exponent), // (floor division)
Relational <, >, <=, >=, == (Equal to), != (Not equal to)
Logical and, or
Assignment =, +=, -=, *=, /=, %=, **=, //=
Membership in, not in (checks if variable is in a sequence)
Identity is, is not (checks if the identity/memory location is the same)
📍 2.5 Punctuators

Punctuators are symbols that are used in programming languages to organize sentence structure, and indicate the rhythm and emphasis of expressions, statements, and program structure.

Examples: ' ', " ", #, \, (), [], {}, @, ,, :, .

3 Barebones of a Python Program
🦴 Components of a Python Program

A typical Python program contains various components:

  • Expressions: Any legal combination of symbols that represents a value. Python evaluates it and produces a value. (e.g., 15, a+5)
  • Statements: A programming instruction that does something (action takes place). It executes and may or may not yield a value. (e.g., print("Hello"), a=10)
  • Comments: Additional readable information to clarify source code. Ignored by Python.
    • Single Line: Starts with #. Can be full line or inline (after code).
    • Multiline (docstrings): Enclosed in triple quotes ''' '''.
  • Functions: A code that has a name and can be reused by specifying its name. Created using the def keyword. Includes a header and a body.
  • Blocks & Indentation: A group of statements part of another statement or function is called a block/suite. Python uses indentation to create blocks of code. Statements requiring a block have a colon (:) at their end.
4 Variables and Assignments
📦 Variables

Named labels, whose values can be used and processed during program run, are called Variables (also Symbolic Variables).

variablename = value a = 10
Lvalues
The objects to which you can assign a value or expression. Can come on LHS or RHS of an assignment statement. (e.g., A in A=10)
Rvalues
The literals and expressions that are assigned to lvalues. Can only come on the RHS. (e.g., 10 or 10+20)
🔄 Multiple Assignments & Dynamic Typing
  • Assigning same value to multiple variables: a = b = c = 10
  • Assigning multiple values to multiple variables: x, y = 10, 20 (Also allows easy swapping: x, y = y, x)
🌟 Dynamic Typing in Python: A variable pointing to a value of a certain type can be made to point to a value/object of a different type later. (e.g., a = 10 then a = "aman" is perfectly valid).
Drawback: It can lead to TypeError if you try to perform unsupported operations on the current type (like dividing a string by an integer).

Note: You can use the type() function to determine the type of an object/variable.

5 Simple Input and Output Functions
📥 Input: input() Function

A built-in function used to accept any value from the user in run-time.

⚠️ Important: The input() function always returns a value of string type.
Format 1 (String):
var = input("Prompt")
Format 2 (Type Conversion):
var = int(input("Prompt"))

You can use int(), float(), or str() to convert the input value into the desired type.

📤 Output: print() Function

Used to print something on the output screen.

Syntax:
print(*objects, sep=' ', end='\n')
  • sep: Separator between multiple objects. Default is a space ' '.
  • end: What to print at the end. Default is a newline '\n'.
print(10, 20, sep='#') 10#20
