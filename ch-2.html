1 Number Systems & Their Bases
🔢 What is a Number System?

A number system is a method of representing numbers using a specific set of digits and a particular base (radix).

Decimal 10 0 – 9

2 Positional Value & Notation
📐 How Positional Value Works

In a positional number system, the value of a digit depends on: (1) the digit itself, (2) its position, and (3) the base of the number system.

✨ Example: (11011)₂ → Decimal
Position:   4    3    2    1    0
Digit:     1    1    0    1    1

= 1×2⁴ + 1×2³ + 0×2² + 1×2¹ + 1×2⁰
= 16 + 8 + 0 + 2 + 1
= (27)₁₀
💡 The rightmost digit always has position 0. Positions increase towards the left.
🔸 Fractional Positional Notation

For digits after the decimal/binary point, positions become negative.

✨ Example: (101.101)₂
Position:   2    1    0   .   -1   -2   -3
Digit:     1    0    1   .    1    0    1

= 1×2² + 0×2¹ + 1×2⁰ + 1×2⁻¹ + 0×2⁻² + 1×2⁻³
2⁻¹ = 1/2 = 0.5 2⁻² = 1/4 = 0.25 2⁻³ = 1/8 = 0.125

4 Decimal → Binary Conversion
🔄 Integer: Repeated Division by 2
  • Divide the decimal number by 2
  • Record the remainder
  • Continue until quotient = 0
  • Read remainders bottom → top
✨ Convert (43)₁₀ → Binary
43 ÷ 2 = 21   R 1
21 ÷ 2 = 10   R 1
10 ÷ 2 = 5    R 0
 5 ÷ 2 = 2    R 1
 2 ÷ 2 = 1    R 0
 1 ÷ 2 = 0    R 1
Read ↑ : (43)₁₀ = (101011)₂
🔄 Fraction: Repeated Multiplication by 2
  • Multiply the fraction by 2
  • Take the integer part (0 or 1)
  • Continue with the fractional part
  • Read integer parts top → bottom
✨ Convert (0.375)₁₀ → Binary
0.375 × 2 = 0.750 → 0
0.750 × 2 = 1.500 → 1
0.500 × 2 = 1.000 → 1
Read ↓ : (0.375)₁₀ = (0.011)₂
5 Decimal → Octal Conversion
🔄 Integer: Repeated Division by 8
✨ Convert (266)₁₀ → Octal
266 ÷ 8 = 33   R 2
 33 ÷ 8 = 4    R 1
  4 ÷ 8 = 0    R 4
Read ↑ : (266)₁₀ = (412)₈
🔄 Fraction: Repeated Multiplication by 8
✨ Convert (0.375)₁₀ → Octal
0.375 × 8 = 3.000 → 3
Read ↓ : (0.375)₁₀ = (0.3)₈
✨ Convert (0.015625)₁₀ → Octal
0.015625 × 8 = 0.125 → 0
0.125    × 8 = 1.000 → 1
Read ↓ : (0.015625)₁₀ = (0.01)₈
6 Decimal → Hexadecimal Conversion
🔄 Integer: Repeated Division by 16
  • Divide by 16, record remainder
  • Convert remainders 10–15 → A–F
  • Read remainders bottom → top
✨ Convert (423)₁₀ → Hexadecimal
423 ÷ 16 = 26   R 7
 26 ÷ 16 = 1    R 10 = A
  1 ÷ 16 = 0    R 1
Read ↑ : (423)₁₀ = (1A7)₁₆
🔄 Fraction: Repeated Multiplication by 16
✨ Convert (0.03125)₁₀ → Hexadecimal
0.03125 × 16 = 0.5 → 0
0.5     × 16 = 8.0 → 8
Read ↓ : (0.03125)₁₀ = (0.08)₁₆
7 Binary → Decimal Conversion
⚡ Integer: Positional Weights (powers of 2)
✨ Convert (11011)₂ → Decimal
= 1×2⁴ + 1×2³ + 0×2² + 1×2¹ + 1×2⁰
= 16   + 8    + 0    + 2    + 1
= (27)₁₀
⚡ Fraction: Negative powers of 2
✨ Convert (0.0101)₂ → Decimal
= 0×2⁻¹ + 1×2⁻² + 0×2⁻³ + 1×2⁻⁴
= 0 + 0.25 + 0 + 0.0625
= (0.3125)₁₀
8 Octal → Decimal Conversion
⚡ Integer: Powers of 8
✨ Convert (372)₈ → Decimal
= 3×8² + 7×8¹ + 2×8⁰
= 192   + 56   + 2
= (250)₁₀
⚡ Fraction: Negative powers of 8
✨ Convert (24.6)₈ → Decimal
= 2×8¹ + 4×8⁰ + 6×8⁻¹
= 16   + 4    + 0.75
= (20.75)₁₀
9 Hexadecimal → Decimal Conversion
⚡ Powers of 16

Multiply every hex digit by the corresponding power of 16. Remember: A=10, B=11, C=12, D=13, E=14, F=15.

✨ Convert (356)₁₆ → Decimal
= 3×16² + 5×16¹ + 6×16⁰
= 768   + 80   + 6
= (854)₁₀
💡 Quick Formula (any base → decimal): For integer part: digit × base^position (rightmost = 0). For fractional part: digit × base^(negative position).
10 Binary ↔ Octal (Shortcut: 3 Bits = 1 Octal Digit)
🔗 Why? Because 8 = 2³
Binary Octal Binary Octal
000 0 100 4
001 1 101 5
010 2 110 6
011 3 111 7
➡️ Binary Integer → Octal

Group binary digits into groups of 3 from right to left. Pad zeros on the left if needed.

✨ Convert (100111010)₂ → Octal
Group: 100 | 111 | 010
       4    7    2
= (472)₈
✨ Convert (11010110)₂ → Octal
Group: 11 | 010 | 110
Pad:   011 | 010 | 110
        3    2    6
= (326)₈
➡️ Binary Fraction → Octal

After the binary point, group bits into sets of 3 from left to right. Pad zeros on the right.

✨ Convert (0.0101)₂ → Octal
Group: 010 | 1
Pad:   010 | 100
        2    4
= (0.24)₈
⬅️ Octal → Binary: Each digit → 3 bits
(472.12)₈
4→100   7→111   2→010
1→001   2→010
= (100111010.001010)₂
11 Binary ↔ Hexadecimal (Shortcut: 4 Bits = 1 Hex Digit)
🔗 Why? Because 16 = 2⁴

➡️ Binary Integer → Hex

Group binary digits into groups of 4 from right to left. Pad zeros on the left if needed.

✨ Convert (001010111010)₂ → Hex
Group: 0010 | 1011 | 1010
        2     B     A
= (2BA)₁₆
➡️ Binary Fraction → Hex

After binary point, group bits into sets of 4 from left to right. Pad zeros on the right.

✨ Convert (0.01011100)₂ → Hex
Group: 0101 | 1100
        5     C
= (0.5C)₁₆
⬅️ Hex → Binary: Each digit → 4 bits
(9F2)₁₆
9→1001   F→1111   2→0010
= (100111110010)₂

13 Common Mistakes to Avoid
⚠️ Don't Make These Errors!
❌ Wrong remainder direction Division remainders → Read bottom to top, NOT top to bottom.
❌ Division for fractions Fractions use multiplication, NOT division.
❌ Wrong hex values A=10, B=11, C=12, D=13, E=14, F=15. Memorize!
❌ Wrong bit grouping Binary→Octal = 3 bits. Binary→Hex = 4 bits.
❌ Padding on wrong side Integer → pad zeros on LEFT. Fraction → pad zeros on RIGHT.
❌ Wrong powers Integer positions: 2⁰, 2¹, 2²…
Fraction positions: 2⁻¹, 2⁻², 2⁻³…
