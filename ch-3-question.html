Section D 2-Mark Written Practice (self-answer, then expand to recheck)
📘 A. Definitions ▶
  1. Define a truth table.
  2. What is a Boolean logical operator? Name the three logical operators given in the chapter.
  3. What is a logic gate?
  4. What is an inverter? State its number of inputs and outputs.
  5. What is a Boolean complement? Give an example.
🔄 B. NOT Operator ▶
  1. What is the NOT operator? Write its symbol and truth table.
  2. Why is NOT called a unary operator? Give one example.
  3. If X = 0, find X'. If Y = 1, find Y'.
  4. Write the truth table for the NOT operation.
➕ C. OR Operator ▶
  1. Define the OR operator. State its symbol and operation name.
  2. Write the truth table of a 2-input OR operation.
  3. Evaluate: (i) 0+0 (ii) 0+1 (iii) 1+0 (iv) 1+1
  4. When does an OR gate produce output 1? Explain with an example.
  5. Write the truth table for a 3-input OR gate.
✖️ D. AND Operator ▶
  1. Define the AND operator. State its symbol and operation name.
  2. Write the truth table of a 2-input AND operation.
  3. Evaluate: (i) 0·0 (ii) 0·1 (iii) 1·0 (iv) 1·1
  4. When does an AND gate produce output 1? Explain.
  5. Write the truth table for a 3-input AND gate.
⚖️ E. Comparison Questions ▶
  1. Differentiate between NOT, OR and AND operators on the basis of type and symbol.
  2. Differentiate between OR gate and AND gate based on their output conditions.
  3. Differentiate between a logical operator and a logic gate.
  4. Differentiate between an OR operation and an AND operation using their truth tables.
📜 F. De Morgan's Theorems ▶
  1. State De Morgan's First Theorem.
  2. State De Morgan's Second Theorem.
  3. Write both De Morgan's theorems.
  4. Using De Morgan's First Theorem, simplify: (A + B)'
  5. Using De Morgan's Second Theorem, simplify: (A · B)'
  6. Simplify (A+B+C)' using De Morgan's theorem.
  7. Simplify (ABC)' using De Morgan's theorem.
  8. Verify De Morgan's First Theorem using a truth table.
  9. Verify De Morgan's Second Theorem using a truth table.
🏗️ G. Circuit Design ▶
  1. Write the Boolean expression given in the PDF for circuit design.
  2. For F = AB + AC' + B'A'C, identify the three separate terms.
  3. For F = AB + AC' + B'A'C, identify which variables require NOT gates.
  4. Explain how to implement AB using a logic gate.
  5. Explain how to implement AC' using NOT and AND gates.
  6. Explain how to implement B'A'C using NOT and AND gates.
  7. Explain the final step required to obtain F = AB + AC' + B'A'C.
  8. Describe the sequence of gates required to realise F(A,B,C) = AB + AC' + B'A'C.
🔥 Top Priority — Do These First
  1. NOT, OR, AND truth tables (2-input and 3-input)
  2. NOT = reverse, OR = any 1, AND = all 1
  3. De Morgan's First: (A+B)' = A'B'
  4. De Morgan's Second: (AB)' = A'+B'
  5. Identify operators, gates, and their symbols
  6. Circuit design: NOT → AND → OR sequence
  7. Read Boolean expressions correctly (A'BC = NOT A AND B AND C)
  8. Truth table rows = 2ⁿ for n inputs
