1 Computer System & Core Processing Cycle
🔄 What is a Computer System?

Computer: An electronic programmable machine that accepts data/instructions as input, processes them, stores data/results, and produces output.  Computer System: hardware + software working together to perform useful tasks.

3 The Central Processing Unit (CPU)
🧠 CPU — the Main Processing Component

The CPU executes instructions and performs the operations required to process data.

🧮 ALUArithmetic Logic Unit — performs arithmetic (+, −, ×, ÷) and logical/comparison operations (<, >, ==).
🕹️ Control UnitControls and coordinates the execution of instructions and movement of data.
⚡ RegistersVery small, very fast storage locations used as temporary working memory during processing.
💡 Memory Cue: ALU = calculate/compare  •  CU = control/coordinate  •  Registers = temporary working storage.
4 Memory: Types, RAM/ROM & Units
📏 Memory Hierarchy
Type Concept
Cache Very fast, small memory reducing access time for frequently needed data
Primary RAM & ROM — used directly for active processing
Secondary Long-term storage: SSD, HDD, pen drive, optical media
1 bit (0/1)➔ 1 Byte = 8 bits➔ KB➔ MB➔ GB➔ TB➔ PB
🔋 RAM vs. ROM
Feature RAM ROM
Full form Random Access Memory Read Only Memory
Volatility Volatile (loses data on power-off) Non-volatile (retains data)
Role Working memory for running programs Stores firmware/start-up instructions
Volatile = needs power Non-volatile = retains without power
5 Types of Software
🧁 System Software
  • Operating System: manages resources, provides user/application services.
  • System Utilities: maintenance, protection & optimization tools.
  • Device Drivers: let the OS communicate with specific hardware.

🍰 Application Software — user-oriented tasks: word processing, browsing, presentations, media playback, education.

🔤 Language Translators
Assembler — Assembly language ➔ Machine code.
Compiler — Translates the entire program to machine code before execution.
Interpreter — Translates & runs the program line-by-line.
