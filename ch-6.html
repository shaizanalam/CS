1 Data Types in Python
📚 Core Data Types

Data type is the way of representing the type of any data. Python offers the following built-in core data types:

1. Numbers (int, float, complex)
2. String ('text')
3. List [1, 2, 3]
4. Tuple (1, 2, 3)
5. Sets {1, 2, 3}
6. Dictionary {'key':'value'}
🔢 Numbers
  • Integer: Whole numbers.
  • Floating Point: Decimal numbers.
  • Complex: Pair of floating point numbers represented as a+bj or a+bi.

The real and imaginary parts of a complex number c can be retrieved through read-only attributes c.real and c.imag.

📝 Strings

A sequence of characters enclosed in quotes '' / "" / ''' '''.

  • Accessed individually using INDEX.
  • +ve index -> 0, 1, 2... (Left to Right)
  • -ve index -> -1, -2, -3... (Right to Left)
  • Immutable in nature.
📋 Lists

Comma-separated values of any datatype between square brackets [].

  • Elements can be accessed using INDEX (+ve or -ve).
  • Mutable in nature (elements can be changed in place).
l = [1, 2, 'a', 'b']
📦 Tuples

Comma-separated values of any datatype between parentheses ().

  • Elements accessed using INDEX.
  • Immutable in nature.
t = (1, 2, 'a', 'b')
⭕ Sets

Comma-separated values enclosed in curly brackets {}.

  • Elements are unordered and unindexed.
  • Do not allow duplicate entries.
  • Cannot contain mutable elements (like lists), but Sets themselves are mutable.
s = {1, 2, 3, 4}
📖 Dictionary

Unordered set of comma separated key:value pairs within {}.

  • No built-in index available (accessed via keys).
  • Dictionary is mutable (values can change).
  • Dictionary keys must be immutable.
  • No two keys can be the same.
d = {10: 'zero', 11: 'one'}
2 Mutable and Immutable Types
🔒 Immutable Types

Types that can never change their values in place. If you change the value, a new object is created in memory.

  • Integers
  • Floating point numbers
  • Booleans
  • Strings
  • Tuples
🔓 Mutable Types

Types whose values can be changed in place without changing their memory location (id).

  • Lists
  • Dictionaries
  • Sets
💡 Variable Internals: Python is object-oriented. Every entity that stores data is an object. Every object has 3 key attributes: type(), value, and id() (memory address).

Important Note: Python creates two different objects even if they store the same value in these cases:

  1. Input of strings from the console.
  2. Writing integer literals with many digits (very big integers).
  3. Writing floating point and complex literals.
3 Operators
⚙️ Types of Operators
Arithmetic: +, -, *, /, // (Floor Div), % (Modulus), ** (Exponent)
Relational: <, >, <=, >=, ==, !=
Logical: and, or, not
Identity: is, is not
Bitwise: & (AND), | (OR), ^ (XOR), ~ (NOT)
🔍 How Relational Operators Work
  • Numeric: Trailing zeros after decimal points are ignored (e.g., 4 == 4.0 is True).
  • Lists & Tuples: Equal if they have the same elements in the same order.
  • Booleans: True is equivalent to 1, False is equivalent to 0.
  • Strings: Compared based on Lexicographical ordering (dictionary order).
    - Capital letters are lesser than small letters.
    - Use ord(char) to get ASCII value, chr(int) to get character.
🔀 Identity vs Equality

== checks if values are identical (Equality).
is checks if both operands refer to the same object memory/id (Identity).

🧠 Logical Operators Deep Dive

Logical operators (and, or, not) can combine expressions or handle truth values of numbers/strings/lists.

  • Truth Value Testing: Every value has a truth value.
    - False: None, False, zero of any numeric type (0, 0.0), empty sequences ('', [], ()), empty mappings ({}).
    - True: All other values.

  • OR Operator (X or Y): If X is true, returns X. Otherwise, returns Y.
  • AND Operator (X and Y): If X is false, returns X. Otherwise, returns Y.
result = '' or 'aman' aman (since '' is false, returns Y) result = [] and [1,2,3] [] (since [] is false, returns X)
⏱️ Precedence & Associativity

Operator Precedence represents the priority of operators (Top to Bottom approach).

Operator Associativity guides the processing direction when an expression has operators of the same priority. Usually follows Left to Right (L2R), but Exponentiation (**) follows Right to Left (R2L).

4 Expressions and Type Casting
📜 Evaluating Expressions

Expressions can be of any type according to the used operators:

  • Arithmetic: 10 + 20
  • Relational: a >= b
  • Logical: a and b
  • String: "aman" + "sharma" (Concatenation) or "aman" * 3 (Replication)
  • Mixed: Combines multiple types.
🔄 Type Casting (Conversion)

Process of converting one type of value into another.

  • Implicit (Type Promotion): Done automatically by compiler (e.g., int + float = float). No conversion if both are integers.
  • Explicit: User-defined using functions like int(), float(), str(), complex(), bool().

A Module is a collection of functions, methods, and constants. Examples: math, random, statistics.

6 Debugging
🐛 Error / Bug & Debugging

An error (bug) is anything in the code that prevents a program from compiling and running correctly. Debugging is the process of locating and correcting the code.

1. Compile Time Error
Occurs during compilation when code is checked against programming rules.
- Syntax Error: Misuse of formal language rules (e.g., missing quotes, wrong indentation).
- Semantics Error: Statements are not meaningful despite being syntactically correct (e.g., A+B=C instead of C=A+B).
2. Logical Error
No syntactical or semantical errors, but program shows unexpected/wrong output due to a logical flaw by the programmer (e.g., using + instead of * for area calculation).
3. Run Time Error
Occurs during the execution (run time) of the program. Harder to find. (e.g., User inputs string 'sdsd' when int() is expected, resulting in ValueError).
🚨 Exceptions: An exception is an irregular, unexpected situation occurring during execution on which the programmer has no control (e.g., ZeroDivisionError, AttributeError).
