📌 2 Marker Questions ▶
  1. What are the three execution orders of a program?
  2. What is an empty statement in Python? Which keyword is used for it?
  3. Differentiate between a simple statement and a compound statement.
  4. What is the difference between `break` and `continue` statements?
  5. Write the output of list(range(1, 10, 2)).
  6. What are the two types of loops in Python? State their alternative names.
  7. When does the else clause attached to a loop execute?
  8. Write a Python program to check whether a given number is odd or even.
  9. Write a Python statement to print a sequence of numbers from 10 down to 1 (in descending order) using the range() function.
  10. What is an infinite loop? How can you break out of it?
📝 3 Marker Questions ▶
  1. Explain the `range()` function and its three formats with examples.
  2. Write a Python program to accept a character and check if it is an uppercase letter, lowercase letter, or a digit.
  3. Differentiate between the `for` loop and the `while` loop.
  4. Write a program to display the factorial of a given input number using a loop.
  5. Write a program to sum the even numbers and odd numbers separately from a range of 1 to 50.
  6. What will be the output of the following code?
    for x in [1, 2, 3]: for y in [4, 5]: print(x, y)
  7. Write a Python program to print a multiplication table for a user-inputted number.
🏆 4 Marker Questions ▶
  1. Write a program to accept 3 numbers from a user and display the largest one using multiple `if` statements.
  2. Write a Python program to print the following pattern:
    * * * * * * * * * * * * * * *
  3. Write a Python program to calculate the area of a circle if the radius is >= 50, otherwise calculate its perimeter.
  4. Write a program to print any 3-digit number in reverse form mathematically (using `%` and `//`).
🏅 5 Marker Questions ▶
  1. Write a complete Python program to accept the marks of 3 subjects and print the grade based on the average.
    - If avg >= 50, print "Grade A"
    - If avg < 50, print "Grade B"
    Include total and average in the final output.
  2. Write a Python program to implement a 'guess the number' game. Python generates a number randomly in the range [10, 50]. The user is given an infinite number of chances to guess the number. When they guess correctly, print "You Win!" and terminate the loop.
  3. Explain the nested `if-elif-else` statement. Provide the syntax and a working program to accept a day number (1-7) and display the corresponding day of the week (e.g., 1=Mon, 2=Tue... 7=Sun). If the input is outside this range, print "Wrong Input".
