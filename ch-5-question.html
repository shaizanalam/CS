Section D Written Practice (2, 3, 4 Markers)
📌 2 Marker Questions ▶
  1. What is a token? List the five types of tokens available in Python.
  2. Define a keyword. Can we use a keyword as an identifier?
  3. Identify the valid and invalid identifiers from the following: Data-Rec, _12, Myfile, 29Kohli, in.
  4. What is a literal? Mention any two kinds of literals used in Python.
  5. Differentiate between an Lvalue and an Rvalue with an example.
  6. What is the use of the input() function? What type of value does it return by default?
  7. Differentiate between the sep and end parameters in the print() function.
  8. What are comments? Name the two types of comments in Python.
  9. Write a statement to assign the value 10 to variables a, b, and c in a single line.
  10. Write the output of: print(10, 20, 30, sep='_').
📝 3 Marker Questions ▶
  1. Write the rules for forming an identifier in Python.
  2. Explain the three types of numeric literals in Python with examples.
  3. Define string literal. How can multiline strings be created in Python?
  4. What is dynamic typing in Python? Explain with a suitable example. What is its drawback?
  5. Identify the types of the following literals: 23.789, "False", True, 0o789, 0XFACE, None. (Note: Mention which ones are invalid if any).
  6. Explain unary and binary operators with one example each.
  7. Write a Python program to obtain three numbers and print their sum and average.
🏆 4 Marker Questions ▶
  1. Explain the barebones (components) of a Python program. Elaborate on expressions, statements, comments, and blocks.
  2. Write a Python program to:
    a. Accept the radius of a circle from the user and calculate its area.
    b. Accept a value in kilometers and convert it into miles (1km = 0.621371 miles).
  3. Given the code below, identify the output and explain how multiple assignment works:
    a,b = 5,10
    a,b = b,a+1
    print(a,b)
  4. Explain Escape Sequences in Python. What is the output of: print("a\bman") and print("d\bhawal\b")? Why?
