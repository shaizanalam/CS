1 What is Python? & History
📌 Basic Definition

Python is a high-level programming language.

  • Programming Language: Used to give instructions to a computer.
  • High-Level: Designed to be relatively easy for humans to read and write, compared to low-level machine languages.
print("Hello World") Hello World
🕰️ History & Influences
  • Developer: Guido van Rossum
  • Developed: February 1991
  • Type: High-level programming language
Influenced by two languages:
  1. ABC
  2. Modula-3
🐍 Why is Python called Python?

The name Python was inspired by the famous BBC comedy show: Monty Python's Flying Circus.

⚠️ Important: Python was not named after the snake. The programming language's name came from the comedy show.
2 Python Pluses (Advantages)

"Python Pluses" means the advantages or features of Python. There are 7 listed in your PDF.

Advantage Meaning / Details
1. Easy to use It has very simple syntax rules (rules for writing correctly). Programs are easy to write and understand.
2. Expressive language Fewer lines of code and simpler syntax. Can perform tasks using fewer instructions (e.g., swapping values: `a, b = b, a`).
3. Interpreted language Executes instructions through an interpreter. Important advantage: It is easy to debug (find and fix errors).
4. Completeness It is a general-purpose language that provides facilities for developing different kinds of programs.
5. Cross-platform language Programs can be used across different operating-system platforms (e.g., Windows, Linux, macOS).
6. Free and open source Available for use without purchasing (Free) and its source code is openly available under its license (Open Source).
7. Variety of usage/applications Used for many different purposes: Web development, Automation, Data processing, AI/ML, Education, etc.
🔄 Expressive Example (Swapping)

The PDF compares swapping two values in C++ and Python.

Traditional Approach:
TEMP = a
a = b
b = TEMP
Python Approach:
a, b = 10, 20
a, b = b, a

Expressive language → fewer lines + simpler syntax

🐛 Debugging & TypeError

Debugging is finding and fixing errors.

x = 10 # integer
y = "20" # string
c = x + y
print(c)
TypeError: unsupported operand type(s) for +: 'int' and 'str'

Error occurs because it tries to add an integer and a string.

3 Python Minuses (Disadvantages)
📉 1. Not the Fastest Language

Its execution can be slower than some other programming languages (like C++ or Java) because it is interpreted and emphasizes simplicity over maximum speed.

📚 2. Lesser Libraries

According to the PDF wording: "Lesser Libraries than C, Java, Perl".

(A library is a collection of pre-written code).

🔗 3. Not Strong on Type-Binding

Python uses dynamic typing, where a variable does not need an explicit type declaration.

C++: int x = 10.25 (Type declared)
Python: a, b = 10, 20 (No type declared, can change later)

🔄 4. Not Easily Convertible

Listed as the fourth disadvantage in the PDF. Because of its lack of syntax (like strong type binding), converting Python code to other languages can be difficult.
